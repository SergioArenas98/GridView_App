Missing media: how Alternative A coexists with images

No media is cleared (content/media/media-rights.json is empty), so no image is shown or generated. A 'loaded' slot is a plain tonal block standing in for the image geometry. Which row gets which state is illustrative only. Back to Alternative A

Rule

  1. A collection whose rows have no media reference renders no image column (Alternative A). This is known from the read model before anything loads.
  2. As soon as any row in the collection has a reference, the 48px column is reserved for every row, so names stay aligned.
  3. Loading: a quiet tray square, no icon. It becomes the image in place.
  4. Failed: the square keeps its size and shows the category icon, so a slot that will not fill reads as settled rather than still loading.
  5. No reference, in a collection that has references: the reserved cell stays empty, no tile.
  6. Loaded: the image fills the same square. Nothing moves in any transition.
